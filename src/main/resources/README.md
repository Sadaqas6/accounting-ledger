# 💰 Accounting Ledger App

## What's This? 🤔
Hey! This is my Accounting Ledger App built with Java.
It lets you keep track of your money — deposits, payments, and everything in between!
Think of it like your own personal bank statement but cooler 😎

## What Can It Do? 🚀
- 💵 Add deposits to your account
- 💸 Track your payments
- 📊 View all your transactions
- 🔍 Search and filter transactions by date, vendor, and more!

## How To Run It 🏃
1. Clone the repo
2. Open it up in IntelliJ IDEA
3. Hit the Run button on AccountingLedgerApp.java
4. Follow the menu and start tracking your money!

## What I Used To Build It 🛠️
- Java 17
- IntelliJ IDEA
- Maven

## Stuff I Learned 💡
- Reading and writing CSV files
- Working with dates and times in Java
- Building a CLI menu application
- ArrayLists and file handling
